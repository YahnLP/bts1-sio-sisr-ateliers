# Ateliers de professionnalisation – BTS SIO SISR

## Principe

Un atelier = une fiche (objectifs, déroulé, livrable) + un guide (méthode, exercices, modèles) + une grille d'évaluation sur 20 points. Les cas sont fictifs.
