# C03 – Superviser un service : indicateurs, seuils, alertes

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Mettre à disposition un service ; répondre aux incidents |
| **Prérequis** | Notions de Linux |
| **Livrable** | Un **tableau de supervision** (indicateur, seuil, action) et un **relevé commenté**. |
| **Co-animation** | Possible avec l'enseignant du bloc technique concerné ou le tuteur. **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Choisir des **indicateurs** pertinents
2. Définir des **seuils** d'avertissement et critique
3. Relever l'état d'un serveur avec des **commandes**
4. Décider de l'**action** selon l'alerte
