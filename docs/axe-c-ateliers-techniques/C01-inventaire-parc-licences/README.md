# C01 – Inventaire du parc et suivi des licences

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Gérer le patrimoine informatique |
| **Prérequis** | Aucun |
| **Livrable** | Une **analyse d'inventaire** et un **plan de renouvellement** chiffré. |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Construire un **inventaire** exploitable
2. Calculer **âge, écarts de licences, obsolescence**
3. Proposer un **plan de renouvellement**
4. Documenter la **méthode** pour le portfolio
