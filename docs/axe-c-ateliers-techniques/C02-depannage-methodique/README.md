# C02 – Dépannage méthodique et traitement d'un ticket

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe C – Ateliers techniques |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Répondre aux incidents et demandes d'assistance |
| **Prérequis** | Aucun |
| **Livrable** | Deux **tickets** complets (diagnostic, action, vérification). |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Appliquer une **démarche** de diagnostic
2. Poser des **hypothèses** et les tester
3. Rédiger un **ticket** complet
4. Clôturer avec **vérification** et **documentation**
