# B02 – Rédiger une procédure technique claire

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Mettre à disposition un service ; répondre aux incidents et demandes |
| **Prérequis** | Aucun |
| **Livrable** | Une **procédure** d'une page, testée par un camarade. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Structurer une **procédure** (objectif, prérequis, étapes, vérification, retour arrière)
2. Écrire des **étapes** courtes et testables
3. Faire **tester** sa procédure par une autre personne
4. Rendre un document **réutilisable**
