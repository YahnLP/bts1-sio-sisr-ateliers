# B03 – Conduire un mini-projet : cadrage, planning, suivi

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Travailler en mode projet |
| **Prérequis** | Aucun |
| **Livrable** | Une **fiche de cadrage**, un **planning** et un **tableau de risques**. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Rédiger une **fiche de cadrage**
2. Découper en **tâches** et dépendances
3. Calculer la **durée totale** et le **chemin critique**
4. Identifier et traiter des **risques**
5. Rédiger un **compte rendu** de suivi
