# B04 – Communication professionnelle : courriel, compte rendu, demande d'assistance

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe B – Ateliers transverses |
| **Durée indicative** | 1 h 30 |
| **Parcours** | **Complément** – Communication professionnelle : la rédaction de messages d'assistance est aussi travaillée dans les tickets de C02. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Répondre aux incidents et demandes ; organiser son développement professionnel |
| **Prérequis** | Aucun |
| **Livrable** | Trois messages rédigés : une demande d'assistance, une réponse à un utilisateur, un compte rendu. |
| **Co-animation** | Possible selon le thème (CEJM, anglais, enseignant du bloc concerné). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Écrire un **courriel professionnel** clair
2. Rédiger une **demande d'assistance** complète
3. Adapter son **vocabulaire** à l'interlocuteur
4. Écrire un **compte rendu**

|---|---|
| 15 min | Principes |

| 15 min | Compte rendu |
| 5 min | Bilan |

## Je sais faire

- [ ] Écrire un objet précis
- [ ] Rédiger une demande d'assistance complète
- [ ] Reformuler sans jargon
- [ ] Rédiger un compte rendu
