# B04 – Communication professionnelle : courriel, compte rendu, demande d'assistance

## 1. Un courriel professionnel

| Élément | Règle |
|---|---|
| **Objet** | Précis : « Imprimante du service compta : panne depuis ce matin » |
| **Destinataire** | Les bonnes personnes ; copie réservée à l'information utile |
| **Introduction** | Une phrase qui dit pourquoi on écrit |
| **Corps** | Faits, une idée par paragraphe |
| **Demande** | Ce qu'on attend, **avant quand** |
| **Politesse** | Formule d'appel et de clôture adaptées |
| **Signature** | Nom, fonction, contact |

## 2. Une demande d'assistance complète

| Information | Exemple |
|---|---|
| **Qui** | Nom et service du demandeur |
| **Quoi** | « Je ne peux plus ouvrir le dossier Production » |
| **Quand** | Depuis quand, à quelle fréquence |
| **Où / avec quoi** | Poste, application, réseau |
| **Message d'erreur exact** | « Accès refusé » (copier le texte) |
| **Ce qui a été essayé** | Redémarrage, autre poste |
| **Urgence et impact** | « Bloque la facturation de 3 personnes » |

**Exercice 1.** Réécris ce message en demande complète :

> Bonjour, ça marche pas, pouvez-vous regarder ? Merci.

<details markdown="1">
<summary>Voir un exemple de réécriture</summary>

*Objet : Impossible d'ouvrir le dossier « Production » depuis ce matin.* Bonjour, je suis Léa Martin (service administratif). Depuis 8 h 30, le dossier « Production » du serveur affiche « Accès refusé » depuis mon poste (PC-07) ; il fonctionnait hier. J'ai redémarré le poste sans effet. Trois personnes du service ont besoin de ce dossier pour la facturation de ce soir. Pouvez-vous regarder avant 14 h ? Merci, cordialement.
</details>

## 3. Répondre à un utilisateur

| À faire | À éviter |
|---|---|
| Reformuler le problème | Répondre sans avoir compris |
| Utiliser des mots **simples** | Jargon (« ACL », « DNS ») sans explication |
| Dire ce qui a été fait et ce qui reste | « C'est réglé » sans détail |
| Donner un **délai** réaliste | Promettre l'impossible |
| Rester **courtois**, même si l'utilisateur est énervé | Se justifier ou accuser |

**Exercice 2.** Reformule la réponse suivante pour une utilisatrice non technicienne :

> Les ACL de ton dossier étaient mal configurées, j'ai modifié le groupe dans l'AD et il faut que tu te reconnectes pour rafraîchir ton token.

<details markdown="1">
<summary>Voir un exemple</summary>

« Bonjour, l'accès à votre dossier « Production » avait été retiré par erreur. Je l'ai rétabli. Pour qu'il soit pris en compte, déconnectez-vous puis reconnectez-vous à votre session. Si le problème persiste, répondez à ce message : je regarde dans l'heure. »
</details>

## 4. Le compte rendu

Un compte rendu se lit en **trente secondes** : date et participants, décisions, actions (qui, quoi, quand), prochaine échéance. Il est envoyé **le jour même**.
