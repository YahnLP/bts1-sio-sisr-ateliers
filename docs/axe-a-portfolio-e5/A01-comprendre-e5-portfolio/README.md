# A01 – Comprendre l'épreuve E5 et construire son portfolio

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 1 h 30 |
| **Compétence(s) visée(s)** | Toutes (vue d'ensemble) ; organiser son développement professionnel |
| **Prérequis** | Aucun |
| **Livrable** | Un **plan de collecte** (tableau remis à la fin de l'atelier). |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Décrire le **format** de l'épreuve E5 (oral, 40 minutes, coefficient 4)
2. Lister le **contenu du dossier numérique**
3. Nommer les **six compétences** du bloc et dire où elles seront démontrées
4. Établir un **plan de collecte** des réalisations sur l'année

## Contenu

| Document | Rôle |

## Déroulé conseillé

| Durée | Activité |
|---|---|
| 15 min | Lecture guidée du format de l'épreuve |
| 20 min | Les six compétences : lire, reformuler |
| 30 min | Autodiagnostic : mes réalisations possibles |
| 20 min | Plan de collecte et échéances |
| 5 min | Bilan |

## Je sais faire

- [ ] Citer la durée et la structure de l'oral E5
- [ ] Lister le contenu du dossier numérique
- [ ] Nommer les six compétences du bloc
- [ ] Dire où je démontrerai chacune
