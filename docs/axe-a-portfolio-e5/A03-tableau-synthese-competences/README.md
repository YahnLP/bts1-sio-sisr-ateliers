# A03 – Tableau de synthèse et couverture des compétences

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 1 h 30 |
| **Compétence(s) visée(s)** | Toutes |
| **Prérequis** | A01, A02 |
| **Livrable** | Ma **matrice de couverture** et un **plan d'action**. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Construire une **matrice** réalisations × compétences
2. Repérer les **compétences non couvertes**
3. Choisir quelles réalisations **présenter à l'oral**
4. Rédiger la **justification** d'une compétence
