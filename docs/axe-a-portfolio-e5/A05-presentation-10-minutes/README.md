# A05 – Préparer la présentation orale de 10 minutes

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 2 h |
| **Compétence(s) visée(s)** | Organiser son développement professionnel |
| **Prérequis** | A02, A03 |
| **Livrable** | Un **plan chronométré** et une **première répétition** enregistrée dans la grille. |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Construire un **plan chronométré** de 10 minutes
2. Concevoir des **supports** sobres
3. S'exprimer clairement en **« je »**
4. Tenir le **temps**
