# A04 – Documenter une réalisation : preuves, schémas, confidentialité

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR – atelier de professionnalisation |
| **Axe** | Axe A – Portfolio et épreuves E5/E6 |
| **Durée indicative** | 2 h |
| **Parcours** | **Cœur** – Preuves, schémas et confidentialité : alimente le portfolio et les fiches. Voir le [parcours cœur et complément](../../ressources/parcours-coeur-complement.md). |
| **Compétence(s) visée(s)** | Mettre à disposition un service ; travailler en mode projet |
| **Prérequis** | A02 |
| **Livrable** | Un **dossier de preuves** pour une réalisation (captures, schéma, journal des tests). |
| **Co-animation** | Possible avec l'enseignant de CEJM (dossier, oral). **À définir avec l'équipe.** |

## Objectifs

À la fin de l'atelier, l'étudiant est capable de :

1. Produire des **captures annotées** exploitables
2. Réaliser un **schéma** lisible
3. **Nommer et ranger** les fichiers de preuve
4. **Anonymiser** ce qui doit l'être

| Document | Rôle |

| Durée | Activité |
|---|---|
| 20 min | Ce qu'est une bonne preuve |
| 30 min | Captures et schémas : exercice |
| 30 min | Nommage et classement |
| 30 min | Confidentialité : relire et nettoyer |
| 10 min | Bilan |

## Je sais faire

- [ ] Annoter une capture
- [ ] Faire un schéma lisible
- [ ] Nommer et classer mes preuves
- [ ] Masquer les données sensibles
- [ ] Tenir un journal de tests
